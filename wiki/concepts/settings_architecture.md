# Архитектура экрана настроек

Документ описывает структуру хранения пользовательских настроек (цели калорийности, БЖУ, антропометрия, темы оформления) и их интеграцию в глобальное состояние приложения.

## Ресурсы и визуализация
*   Интерактивная архитектурная схема: [settings_architecture_plan.html](../../settings_architecture_plan.html) — визуализирует схему разделения настроек на группы и потоки данных (Data Flow) между UI и Zustand-хранилищем.

## Ключевые компоненты
- **Настройки профиля**: Антропометрические данные (вес, рост, процент жира), используемые для расчета базового метаболизма (BMR).
- **Цели по нутриентам**: Конфигурация калорийности и автоматический расчет БЖУ на основе выбранной цели (Bulk, Cut, Recomp, Maintenance).
- **Синхронизация состояния**: Хранилище Zustand с сохранением в `localStorage` для поддержки автономной работы PWA.
