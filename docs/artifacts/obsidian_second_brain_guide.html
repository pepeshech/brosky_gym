Установка в Anthropic Claude Code

Claude Code поддерживает концепцию "навыков" (skills) нативно. Установка занимает одну команду:

bash 
curl -fsSL https://raw.githubusercontent.com/eugeniughelbur/obsidian-second-brain/main/scripts/quick-install.sh | bash

Скрипт выполнит клонирование репозитория в папку ~/.claude/skills/obsidian-second-brain и создаст символические ссылки для CLI-команд в ~/.claude/commands/.

После завершения установки перезапустите Claude Code и выполните инициализацию внутри вашего Vault:

claude terminal 
/obsidian-init

Настройка для Gemini CLI / Codex CLI / OpenCode

Для платформ, не поддерживающих прямую линковку навыков, репозиторий предоставляет сборщик, генерирующий специализированный роутер команд.

1. Клонируйте репозиторий локально:

bash 
git clone https://github.com/eugeniughelbur/obsidian-second-brain
cd obsidian-second-brain

2. Соберите платформу (например, для gemini-cli или opencode):

bash 
bash scripts/build.sh --platform gemini-cli
# Или: codex-cli, opencode, pi

3. Скопируйте собранные файлы в корень вашей Obsidian папки (Vault):

bash 
cp -R dist/gemini-cli/. /path/to/your/vault/

Ассистент при запуске из этой директории увидит файл конфигурации (например, GEMINI.md) и загрузит команды автоматически.

Настройка API ключей для Research-модулей

Инструменты веб-поиска и парсинга требуют ключи внешних API. Конфигурационный файл должен находиться по пути: ~/.config/obsidian-second-brain/.env

Скопируйте шаблон и пропишите туда ключи:

bash 
mkdir -p ~/.config/obsidian-second-brain
cp .env.example ~/.config/obsidian-second-brain/.env
chmod 600 ~/.config/obsidian-second-brain/.env
Переменная в .env Сервис Для каких команд нужна
XAI_API_KEY console.x.ai /x-read, /x-pulse, сборка комментариев в YouTube
PERPLEXITY_API_KEY Perplexity API /research, /research-deep (высокая точность)
GEMINI_API_KEY Google AI Studio /notebooklm (интегрированный поиск по файлам)
OPENAI_API_KEY OpenAI Platform Whisper транскрипция для /podcast

Включение семантического (векторного) поиска

По умолчанию поиск по Vault работает через быстрый поиск по вхождению ключевых слов. Вы можете включить векторный поиск, который будет находить файлы по общему смыслу запроса.

1. Установите локально Ollama (ollama.com) и скачайте embedding-модель:

bash 
ollama pull mxbai-embed-large

2. Постройте векторный индекс вашей базы знаний:

bash 
uv run python scripts/eval/semantic_search.py --path "/path/to/vault" --build

3. Пропишите в настройках переменную OBSIDIAN_SEARCH_SEMANTIC=1. Теперь поиск объединит результаты текстового совпадения и семантического анализа.

Концепция AI-First Заметок (The AI-First Rule)

Основное отличие философии Second Brain от обычного ведения заметок: заметки структурированы под чтение машиной (LLM), а не человеком. Когда ИИ обращается к вашему Vault, он должен мгновенно получить контекст, уровень уверенности информации, историю изменений и источник.

Пример разметки заметки (wiki/concepts/some_topic.md) 
---
type: Concept
title: Реакторы слияния на боре
confidence: high
sources: [arxiv.org/abs/2604.1102]
timestamp: 2026-06-29T17:15:00Z
---

## For future Claude
> [!IMPORTANT]
> Данный концепт содержит выжимку по безнейтронному синтезу p-11B. Учитывать при решении энергетических задач. Последнее обновление опровергло модель удержания 2025 года.

# Суть концепта
Здесь располагается структурированное описание...

## Хронология изменений (Bi-temporal audit)
- 2025-10-12: Первоначальное суждение на базе постов @physic_guy (уверенность: low).
- 2026-06-29: Статья на ArXiv подтвердила эффективность лазерного поджига (уверенность: high).

Расписание работы фоновых агентов

Ваш ИИ-мозг не спит. Пока вы не используете терминал, система запускает четыре регулярные задачи для поддержания структуры и актуальности базы знаний.

8:00 AM — Morning Agent

Утренний брифинг

Агент инициализирует ежедневную заметку (/obsidian-daily), подгружает ваши задачи из календаря и выводит список приоритетов и просроченных тасков.

После compaction — Background Agent

Фоновое индексирование

Запускается автоматически сразу после сжатия контекста CLI. Проводит быстрый проход по измененным за сессию файлам, обновляет связи и индексы каталогов.

10:00 PM — Nightly Agent

Ночная консолидация

Самый тяжелый агент. Выполняет 5 фаз: закрывает день, примиряет противоречия в фактах (reconcile), ищет неявные паттерны за неделю (synthesize), чистит "осиротевшие" заметки и пересобирает индекс.

Пятница 6:00 PM — Weekly Review

Недельный ретроспективный анализ

Компилирует итоги недели. Сравнивает запланированные проекты с реально выполненными задачами, заносит выводы в архивы и формирует фокус на следующую неделю.
