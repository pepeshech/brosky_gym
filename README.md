# Brosky Gym 🏋️‍♂️

Brosky Gym is a modern, privacy-focused fitness and nutrition tracking application built with React, TypeScript, and Vite. It serves as a comprehensive "Second Brain" for athletes, offering advanced workout tracking, nutrition logging, and progress visualization.

## Features ✨

- **Workout Tracking:** Log exercises, track PRs, and manage workout sessions with a built-in timer.
- **Nutrition Logging:** Precise macronutrient tracking (Calories, Protein, Fat, Carbs) with an offline food database and customizable meals.
- **Advanced Dashboard:** Daily rings and heatmaps for quick visualization of your progress and recovery.
- **Local First & Privacy Focused:** All your data is stored locally in your browser. No mandatory cloud syncing, complete privacy.
- **Offline Mode (PWA):** Works perfectly without an internet connection. Install it on your phone like a native app.

## Tech Stack 🛠️

- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Architecture:** Local-first (Offline Ready)

## Getting Started 🚀

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/pepeshech/brosky_gym.git
   ```
2. Navigate to the app directory:
   ```bash
   cd brosky_gym/app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
