# Brosky Gym Tracker Pro 🏋️‍♂️💪

> **Научно-обоснованный спортивный трекер тренировок и КБЖУ с локальной авторегуляцией нагрузки, динамической моделью TDEE и встроенным спортивным глоссарием.**

---

## 🌟 Философия и Главные Особенности

**Brosky Gym** создавался как автономный «Второй Мозг» для атлетов всех уровней — от новичков до профессиональных бодибилдеров и пауэрлифтеров. Приложение полностью фокусируется на научном подходе к гипертрофии и сжиганию жира (Renaissance Periodization, RTS, MacroFactor), гарантируя **100% приватность данных** (все замеры и логи хранятся исключительно в вашем браузере).

### 🚀 Ключевые возможности:

1. **🏋️ Силовой автопилот и Авторегуляция (RIR / RPE / 1RM)**
   - **Автоматический расчёт рабочих весов**: Движок отслеживает ваш прошлый запас повторов (RIR), степень отсроченной мышечной боли (DOMS) и тоннаж, подбирая идеальный вес на следующую сессию.
   - **Защита связок и фасций**: При высокой боли (DOMS) система автоматически снижает нагрузку на 15% для полного восстановления.
   - **Расчет 1RM (Одноповторный максимум)**: Динамический вычисление силового рекорда по формулам Epley и Тачшерера в реальном времени прямо во время тренировки.

2. **⚡ Динамический ТДEE и Макросы (MacroFactor EMA Model)**
   - **Экспоненциальное сглаживание EWMA**: Забудьте о панике при скачках веса из-за задержки воды. Алгоритм вычисляет чистый суточный расход калорий (TDEE).
   - **Двойной расчёт BMR**: Уравнения Маффлина-Джеора и Катча-МакАрдла по чистой сухой массе (LBM).
   - **Пресеты питания**: Быстрое переключение фаз — *Сушка (-20%)*, *Поддержание*, *Набор массы (+10%)*, *Refeed (углеводный рефид)*, *LCHF (кето-день)* и *Fast (разгрузка)*.

3. **🎨 Кастомный дизайн-пак BroskyIcon (Precision Dual-Tone SVG)**
   - 51 авторская двухтональная SVG-иконка в строгом атлетическом стиле (олимпийский гриф с замками, анатомическая модель бицепса, электронные смарт-весы, сканер КБЖУ, мишени RIR).
   - Поддержка фирменной палитры макросов (белок, жиры, углеводы, рост, сушка).

4. **📖 Встроенный Глоссарий и Справочник Терминов**
   - Полный интерактивный справочник в разделе **«Настройки»** ⚙️ с мгновенным поиском по терминам (`RIR`, `RPE`, `TDEE`, `BMR`, `NEAT`, `EAT`, `TEF`, `MEV`, `MAV`, `MRV`).

5. **📱 PWA & Полный Offline (Local-First)**
   - Приложение работает 100% без интернета. Поддерживает установку на смартфон/ПК как нативное приложение (PWA).

## 📖 Как пользоваться приложением (Инструкция)

### 1. Настройка Профиля (Первый Запуск)
1. Перейдите во вкладку **«Настройки»** ⚙️.
2. Укажите ваш текущий вес, рост, возраст, процент жира и целевое количество шагов (NEAT).
3. Приложение автоматически вычислит ваш **BMR** и базовую норму КБЖУ.

### 2. Проведение Тренировки
1. Откройте вкладку **«Тренировки»** 🏋️.
2. Выберите готовый шаблон или воспользуйтесь **«Смарт-Генератором»** под ваш инвентарь (штанга, гантели, тренажеры).
3. Введите выполненные веса и повторы. Нажмите **«Заполнить Автопилот»** — система проанализирует ваш RIR и автоматически предложит следующий рабочий вес.

### 3. Ведение Дневника Питания
1. Перейдите во вкладку **«Питание»** 🥣.
2. Добавляйте продукты из встроенной оффлайн-базы или используйте штрих-код сканер.
3. Отслеживайте кольца дневной нормы белков, жиров и углеводов.

### 4. Отслеживание Прогресса
1. Перейдите во вкладку **«Прогресс»** 📈.
2. Вносите утреннее взвешивание. График EWMA покажет реальный тренд сжигания жира или набора мышц без ложных дневных отеков.

## 🛠️ Технологический Стек

- **Frontend**: React 18 + TypeScript (Strict Mode)
- **Сборщик**: Vite 8 (Rolldown engine)
- **Стилизация**: Tailwind CSS (Liquid Glass UX/UI, HSL токенизация)
- **State Management**: Zustand
- **Иконпак**: BroskyIcon.tsx (51 кастомный dual-tone SVG компонент)
- **PWA Service Worker**: Vite Plugin PWA (Workbox 7)
- **Тестирование**: Vitest (100% pass)

## 💻 Локальный запуск и Разработка

### Требования
Установленный [Node.js](https://nodejs.org/) (версия 18+).

### Пошаговый запуск

1. **Клонировать репозиторий**:
   ```bash
   git clone https://github.com/pepeshech/brosky_gym.git
   cd brosky_gym/app
   ```

2. **Установить зависимости**:
   ```bash
   npm install
   ```

3. **Запустить режим разработки (Live HMR)**:
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:5173/](http://localhost:5173/) в браузере.

4. **Сборка продакшн-бандла**:
   ```bash
   npm run build
   ```

5. **Просмотр встроенного сервера предпросмотра**:
   ```bash
   npm run preview
   ```
